# 本地输入与开发运行

完整步骤见 [REPRODUCE.md](REPRODUCE.md)，当前问题和代码入口见 [HANDOFF.md](HANDOFF.md)。

需要自己有权使用的同版本游戏、密钥和固件。输入和全部生成结果保存在仓库外；脚本接收密钥文件路径，不填写或输出密钥内容，不自动下载游戏或密钥。

`tools/prepare_fc27.py` 接齐提取、独立离线 NSO 规范化、renderer 提取、普通指令改写与严格输出哈希核对；可选的 `prepare_menu.py` 从本机原输入重建菜单实验 232 的四个资源文件。`tools/run_fc27.py` 建立新的隔离测试 App、profile 和缓存。普通启动器源码仍保留，实验复现请使用上述入口。

build ID、NPDM 及资源的完整哈希不相符时流程会停止，文件名或版本标签相同不代表兼容。规范化用的 GPL-2.0 解码工具独立运行，不打入 Rust/App。游戏文件、解码器二进制、规范化/改写模块、修改后资源、缓存和开发者存档均未分发。

公开导出移除了可选的 Unicorn 指令等价验证器和来源待进一步确认的捕获测试夹具，见 `PROVENANCE.json`。不要将哈希一致、正常退出或忽略的测试视为完整游戏验收。
